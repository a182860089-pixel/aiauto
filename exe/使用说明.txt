病例自动传 — 发给别人也能直接用

一、对方电脑需要什么
- Windows 10 / 11 64 位
- 不需要安装 Node.js、Python 或本项目源码
- 能上网（识别图片要调用 OCR 接口，登录平台要打开规培网站）

二、怎么发给别人
1. 把「病例自动传-0.1.0-安装包.exe」发给对方（推荐）
2. 对方双击安装，按提示选目录，完成后桌面会出现「病例自动传」
3. 如果安装包发不过去，也可以发 zip 压缩包：解压后双击「病例自动传.exe」

三、第一次打开
- 若 Windows 提示「已保护你的电脑」：点「更多信息」→「仍要运行」
- 打开后先到「识别工作台」，填写硅基流动 OCR API Key，点保存
- 平台自动化页填写自己的规培账号密码（只在本机使用，不会写进安装包）

四、日常使用
1. 上传病历图片 → 识别 → 核对记录类别和科室
2. 需要表格时导出 Excel
3. 到「平台自动化」登录后，把已核对记录填入住院病种记录
4. 科室下拉来自平台真实科室，识别结果会按名称自动匹配

五、注意事项
- 每台电脑都要各自填写 OCR Key 和平台账号
- 杀毒软件可能拦截未签名程序，加入白名单即可
- 卸载不会删除本机已保存的 OCR 设置；可在系统设置里卸载「病例自动传」
